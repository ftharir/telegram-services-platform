# Telegram Services Platform

بستر ارائه‌دهنده خدمات تلگرام با معماری اسنپ‌شات‌محور و مدیریت سفارش‌ها.

## وضعیت پروژه

- **فاز ۱:** پایه دیتابیس، زیرساخت و احراز هویت اولیه (کامل شده)
- **فاز ۲:** مدیریت سفارش‌ها، کیف‌پول و اتصال به RapidSeen API (کامل شده - ۱۰۰٪)

## ویژگی‌های پیاده‌سازی‌شده در فاز ۲

1. **مدیریت سفارش‌ها و اسنپ‌شات قیمت‌ها:**
   - ثبت سفارش‌ها همراه با کد پیگیری اختصاصی (`ORD-XXXXXXXX`).
   - ذخیره اسنپ‌شات قیمت و مشخصات سرویس در زمان ثبت سفارش.

2. **سیستم کیف‌پول (Wallet & Transactions):**
   - کسر اعتبار (`debit`) و افزایش اعتبار (`credit`) به‌صورت ترکنش‌های اتمیک.
   - مدیریت خطای کسر اعتبار با `InsufficientBalanceError`.

3. **یکپارچه‌سازی با RapidSeen API:**
   - سرویس‌های ارسال سفارش، دریافت وضعیت، و درخواست لغو (`cancel_order`).
   - نگاشت وضعیت‌های خارجی به `OrderStatus` داخلی.

4. **چرخه عمر سفارش و مرجوعی دقیق (Refund):**
   - محاسبه متناسب مبلغ مرجوعی برای سفارش‌های ناقص (Partial) و لغوشده (Canceled).
   - مکانیزم جلوگیری از مرجوعی تکراری (Double Refund Protection).
